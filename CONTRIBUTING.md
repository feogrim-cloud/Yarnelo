# Участие в разработке Yarnelo

Спасибо за интерес к проекту. Для небольшого исправления можно сразу открыть pull request; крупную функцию удобнее сначала обсудить в [issue](https://github.com/feogrim-cloud/Yarnelo/issues).

## Сообщение об ошибке

Укажите версию Yarnelo и Windows, шаги воспроизведения, ожидаемое и фактическое поведение. Для ошибок отображения полезны масштаб экрана, количество мониторов и скриншот. Для проблем с играми укажите режим окна и монитор, на котором находится панель.

Перед публикацией скриншотов и журналов удалите личные пути и другие данные, которыми не хотите делиться. Не прикладывайте свою папку `Data`: она содержит настройки и ярлыки.

## Изменения кода

- Сохраняйте совместимость с Windows 11 x64, WPF и .NET Framework 4.8.
- Ограничивайте pull request одной задачей и объясняйте изменение поведения.
- Сохраняйте содержимое ярлыков, параметры запуска и возможность их восстановления. Изменение формата данных должно учитывать существующие профили.
- Не добавляйте пользовательские настройки, ярлыки, журналы и собранные файлы в репозиторий.

Сборка и проверки из корня репозитория:

```powershell
.\src\Build.ps1 -Output .\build
.\scripts\Test.ps1
```

При изменениях интерфейса проверьте затронутый сценарий вручную и опишите результат в pull request. Для изменений видимости панели проверьте перекрытие окнами, возврат после сворачивания, несколько мониторов и полноэкранный режим.
