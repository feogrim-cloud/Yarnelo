<h1 align="center">Yarnelo</h1>

<p align="center">Ваши ярлыки. В одном месте.</p>
<p align="center"><a href="README.md">English</a> · <strong>Русский</strong></p>

Yarnelo — полупрозрачная панель ярлыков для **Windows 10/11 и Linux**, вдохновлённая формой macOS Dock. Соберите любимые приложения, игры, папки и файлы в одном месте, выберите от одного до четырёх рядов и освободите рабочий стол.

**[Скачать последнюю версию](https://github.com/feogrim-cloud/Yarnelo/releases/latest)** · [Установка](docs/INSTALL.ru.md) · [Сообщить о проблеме](https://github.com/feogrim-cloud/Yarnelo/issues)

## Скриншоты

Демонстрации интерфейса Windows, отрисованные Yarnelo с примерами ярлыков на нейтральном фоне. Изображённые приложения и игры не входят в комплект; права на их значки принадлежат соответствующим владельцам. [Подробности и источники значков](assets/screenshots/README.md).

## Возможности

- До **30 ярлыков**: от одного до четырёх выбранных рядов и автоматический перенос, если места на экране недостаточно.
- Настраиваемые непрозрачность и скругление фона — от прямых углов до капсулы; размер значков, увеличение при наведении и подписи.
- Размещение по центру сверху, снизу, слева или справа. Боковая панель становится вертикальной; перетаскивание ручки включает свободное размещение.
- Широкое окно настроек в два столбца: все пункты на одной странице без вертикальной прокрутки.
- Плавные анимации наведения, нажатия и перестановки: соседние значки освобождают место при перетаскивании.
- Добавление приложений, файлов, папок, «Этот компьютер» / «Компьютер» и Корзины.
- **Русский и английский интерфейс:** правая кнопка по панели → **Язык / Language** → **Русский / English**. Выбор сохраняется и применяется без перезапуска. При первом запуске используется русский для русской локали системы, английский — для остальных.
- Локальные настройки и хранение ярлыков; приложение не отправляет ваши данные на сервер.

В **Windows** ярлыки `.lnk` и `.url` можно переносить с рабочего стола в панель и возвращать через меню значка. Есть меню в области уведомлений, необязательный запуск при входе, автоматическое скрытие при перекрытии её места и определение полноэкранных приложений на мониторе панели. Возвращение не переключает фокус. Режим поверх обычных окон также уступает полноэкранным и безрамочным приложениям на мониторе панели.

В **Linux preview** поддерживаются `.desktop`, файлы, папки, «Компьютер» и Корзина. Панель хранит ссылки на исходные файлы и **не переносит их с рабочего стола**. Рекомендуется **X11**; в сеансе Wayland готовые сборки используют XWayland. Размещение окна зависит от композитора; Windows-механизм определения перекрытия и полноэкранных игр пока не перенесён. [Подробности Linux](docs/LINUX.ru.md).

Для Windows x64/x86 нужен **.NET Framework 4.8 или 4.8.1**; для нативной Windows ARM64 — **Windows 11 и .NET Framework 4.8.1**. Windows 10 ARM64 не поддерживается нативным ARM64-пакетом. EXE пока не подписаны сертификатом разработчика. Linux-пакеты включают Python и Qt, но требуют системные библиотеки из инструкции: **glibc 2.35+ для x86_64**, **glibc 2.39+ для ARM64**. ARM64-пакеты не поддерживают Debian 12 и Ubuntu 22.04. Windows 7/8.1, 32-битный Linux и Alpine/musl не входят в совместимость этого выпуска. Linux-версия имеет статус preview; это не утверждение о проверке каждого дистрибутива и окружения рабочего стола. [Как выбрать архитектуру](docs/INSTALL.ru.md#какой-файл-скачать).

## Начало работы

1. Установите подходящий `Setup.exe` Windows либо полностью распакуйте ZIP в постоянную доступную для записи папку и запустите `Yarnelo.exe`. В Linux установите DEB/RPM или разрешите исполнение AppImage; см. [инструкцию](docs/INSTALL.ru.md).
2. Перетащите ярлыки на панель или добавьте их через **+**. Перетаскивание внутри панели меняет порядок.
3. Правая кнопка по панели открывает **Настройки**, **Язык** и **Выход**. Ручка перемещает панель свободно.
4. В **Настройках** выберите край экрана, число рядов, непрозрачность и скругление фона, размер значков и увеличение. При нехватке места панель добавит ряды, а у бокового края — столбцы.

### Хранение ярлыков в Windows

При включённом переносе ярлыки `.lnk` и `.url` с вашего рабочего стола сохраняются в `Data/Library`, затем убираются с рабочего стола. Их содержимое и параметры запуска сохраняются. Обычные файлы и папки добавляются без перемещения. Чтобы вернуть перемещённый ярлык, выберите **«Убрать и вернуть ярлык на рабочий стол»** в его меню; существующие файлы не перезаписываются. Для переноса или возврата общих ярлыков Windows может запросить права администратора.

Настройки находятся в `Data/settings.json`, резервная копия — в `Data/settings.json.bak`. Маркер `portable.mode` включает хранение данных рядом с программой. Выберите постоянную папку до добавления ярлыков: профиль сохраняет абсолютные пути. Обновляйте приложение **в прежней папке**, сохраняя `Data`. Новый установщик не импортирует отдельный переносной профиль автоматически. Перед удалением верните нужные ярлыки и отключите запуск при входе. [Обновление и удаление в Windows](docs/WINDOWS.ru.md).

В Linux настройки сохраняются в `$XDG_CONFIG_HOME/yarnelo/settings.json` или `~/.config/yarnelo/settings.json`. Профили Linux и Windows независимы.

## Используемый стек

| Часть проекта | Технологии |
| --- | --- |
| Приложение Windows | **C#**, **WPF**, **.NET Framework 4.8** для x64/x86 и **4.8.1** для ARM64; нативная интеграция **Win32 / Windows Shell**, данные **DWM** о границах и видимости окон |
| Приложение Linux | **Python 3.12**, **PySide6 Essentials / Qt 6**; Qt Widgets, анимации Qt, локальные настройки JSON, `gio launch` и `xdg-open` |
| Упаковка Windows | **PowerShell**, компилятор .NET Framework для x64/x86 и Roslyn для ARM64, **Inno Setup 6**; установщики EXE и переносные ZIP для x64/x86/ARM64 |
| Упаковка Linux | **PyInstaller**, **appimagetool / AppImage**, **fpm** для DEB/RPM, переносной TAR.GZ; нативная сборка Ubuntu 22.04 x86_64 и Ubuntu 24.04 ARM64 |
| Проверки и релизы | **GitHub Actions** для Windows и Linux; проверки хранилища и интерфейса C#, Python `unittest`, отрисовка Qt, проверки установщика Windows, установка DEB/RPM и списки SHA-256 |
| Графика приложения | Собственные PNG, SVG и ICO нескольких размеров; генерация иконки Windows через PowerShell / System.Drawing |

Обе версии используют нативные библиотеки интерфейса. Yarnelo не встраивает браузер и не запускает веб-сервер.

## Сборка из исходников

Для Windows x64/x86 используется системный компилятор .NET Framework; Visual Studio, отдельный .NET SDK и NuGet для этих архитектур не нужны. Из корня репозитория в Windows PowerShell:

```powershell
.\src\Build.ps1 -Architecture x64 -Output .\build
.\build\Yarnelo.exe
.\scripts\Test.ps1
```

Для x86 укажите `-Architecture x86`. Для нативной ARM64 используются `-Architecture arm64` и дополнительные средства сборки; см. руководство Windows. Генератор создаёт PNG, SVG и ICO нескольких размеров. [Упаковка Windows](docs/WINDOWS.ru.md#сборка-для-разработчиков) · [Разработка и упаковка Linux](linux/README.md).
