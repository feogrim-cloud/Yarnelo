# Windows: установка и обновление

[English](WINDOWS.md) · **Русский**

В [релизах Yarnelo](https://github.com/feogrim-cloud/Yarnelo/releases) доступны настоящие исполняемые файлы Windows и архивы без установки. Для Windows 10 и Windows 11 используется одна совместимая сборка, отдельная программа для каждого обновления Windows не требуется.

| Система | Рекомендуемый файл | Без установки |
| --- | --- | --- |
| Windows 10 / 11, Intel или AMD, 64 бита | `Yarnelo-Windows-x64-Setup.exe` | `Yarnelo-Windows-x64-Portable.zip` |
| Windows 10, 32 бита | `Yarnelo-Windows-x86-Setup.exe` | `Yarnelo-Windows-x86-Portable.zip` |
| Windows 11, ARM64 (например Snapdragon) | `Yarnelo-Windows-arm64-Setup.exe` | `Yarnelo-Windows-arm64-Portable.zip` |

Узнать архитектуру: **Параметры → Система → О системе → Тип системы**. Для 64-битных Intel/AMD выбирайте x64, для ARM-процессоров вроде Snapdragon — ARM64. x86 предназначена для 32-битной Windows 10. Это отдельные нативные сборки приложения; ARM64 не является переупакованным x64-файлом для эмуляции.

Для Windows x64/x86 нужен **Microsoft .NET Framework 4.8 или 4.8.1**. Для нативной ARM64 — **Windows 11 и .NET Framework 4.8.1**. Windows 10 ARM64, Windows 7 и Windows 8.1 не входят в совместимость этого выпуска. Установщик проверяет нужный компонент. Официальные загрузки: [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48) · [.NET Framework 4.8.1](https://dotnet.microsoft.com/download/dotnet-framework/net481).

## Внешний вид и расположение панели

Правая кнопка по панели → **Настройки**. Все пункты находятся в двух столбцах без вертикальной прокрутки; окно уменьшается только при нехватке доступного места. **Скругление углов**: 0 — прямые углы, промежуточные значения — мягкое скругление, 100 — капсула. Непрозрачность фона не изменяет непрозрачность значков.

Выберите расположение по центру **сверху, снизу, слева или справа** на текущем мониторе панели. У бокового края панель вертикальная, значки обычной ориентации. Перетаскивание ручки включает свободное размещение. Выбранные 1–4 ряда у бокового края становятся столбцами. При нехватке места автоматически добавляются ряды/столбцы, затем при необходимости уменьшаются значки; исходный выбор сохраняется. Положение у края пересчитывается при изменении размера панели.

## Установщик .exe

1. Скачайте подходящий `Setup.exe` из раздела Assets выбранного релиза.
2. Запустите файл и пройдите мастер установки. Права администратора не нужны. По умолчанию программа находится в `%LOCALAPPDATA%\Programs\Yarnelo`.
3. Ярлык появится в меню «Пуск». Ярлык на рабочем столе можно включить в мастере.
4. Запустите Yarnelo из меню «Пуск» и перетащите ярлыки на панель. Автозапуск при входе включается отдельно в настройках панели.

Файлы пока не подписаны сертификатом разработчика. Если Windows покажет SmartScreen, проверьте, что файл получен именно из релизов `feogrim-cloud/Yarnelo`. Для проверки целостности скачайте из того же релиза `SHA256SUMS`, откройте PowerShell в папке загрузки и выполните:

```powershell
Get-FileHash .\Yarnelo-Windows-x64-Setup.exe -Algorithm SHA256
```

Полученный хеш должен совпадать со строкой для этого имени файла в `SHA256SUMS`. Для x86, arm64 или ZIP подставьте соответствующее имя. Контрольная сумма подтверждает целостность загруженного файла, но не заменяет цифровую подпись разработчика.

## Переносная версия

1. Скачайте `Portable.zip` нужной разрядности.
2. Распакуйте **все файлы** в постоянную папку, доступную для записи, например `Документы\Yarnelo`. Не запускайте программу прямо из архива.
3. Запустите `Yarnelo.exe`.

В обоих вариантах `portable.mode` хранит настройки и библиотеку в папке `Data` рядом с программой. Не удаляйте этот файл. Не переносите заполненную папку: в профиле сохранены абсолютные пути к импортированным ярлыкам.

## Интерфейс и язык

Правая кнопка по пустому месту панели → **Язык / Language → Русский / English**. Интерфейс меняется без перезапуска, выбор сохраняется. При первом запуске используется русский для русской локали системы, английский — для остальных. Язык Yarnelo не меняет язык Windows и не переименовывает ваши файлы и ярлыки.

Кнопка **+** добавляет файлы, папки, «Этот компьютер» и Корзину. Перетаскивание значков меняет порядок; ручка слева перемещает панель. В **Настройках** доступны ряды, непрозрачность фона, размер, увеличение, подписи, запуск при входе и показ поверх обычных окон.

## Автозапуск при входе

Включите **Настройки → Запускать при входе в Windows**. Yarnelo создаст задачу входа для вашей учётной записи с задержкой 10 секунд, точным путём к программе и её папкой в качестве рабочей. Задача использует обычные права вашей учётной записи, разрешена при работе от батареи и не ограничена по времени выполнения.

Задача отображается в **Планировщике заданий → Библиотека планировщика заданий** под именем `Yarnelo.Logon.<SID>`, где `<SID>` — идентификатор вашей учётной записи. Управляйте ею через переключатель Yarnelo; в планировщике можно проверить **Триггеры**, **Действия** и **Результат последнего запуска**. Задачи планировщика обычно не отображаются в **Диспетчере задач → Автозагрузка приложений**. Прежняя строка «Polka» там не показывает состояние новой задачи.

При первом обычном запуске после обновления до 1.7.1 включённая прежняя запись, указывающая на эту установку, переносится. Старая запись Run удаляется только после сохранения и проверки новой задачи. Задача или прежний автозапуск, отключённые в Windows, не включаются автоматически. Чтобы явно включить автозапуск, используйте переключатель Yarnelo; при необходимости выключите и включите его снова. При ошибке появится сообщение, а переключатель вернётся в прежнее состояние.

Выключение автозапуска удаляет только задачу этой установки и соответствующую прежнюю запись. Другие программы и другие папки установки Yarnelo не затрагиваются. Проверка сохранённой задачи или запуск вручную подтверждают её команду; автоматическое срабатывание подтверждается при следующем входе в Windows. Для этой проверки Yarnelo не завершает ваш сеанс и не перезагружает Windows.

## Обновление без потери ярлыков

Для установленной версии запускайте новый установщик **в ту же папку**. Он мягко закрывает только соответствующий процесс Yarnelo. Если программа не отвечает, установка остановится и предложит закрыть её вручную; принудительного завершения нет. Содержимое `Data` и существующее предпочтение автозапуска сохраняются.

Для переносной версии выйдите из Yarnelo через меню в области уведомлений и распакуйте новый архив поверх файлов **в прежней папке**, сохранив `Data`. Перед обновлением полезно сделать резервную копию всей папки. Не переносите старый профиль в новую папку установки простым копированием `Data`: его абсолютные пути останутся прежними.

При переходе на устройстве Windows 11 ARM с эмулируемой версии на нативную ARM64 закройте Yarnelo и сохраните резервную копию всей прежней папки. Установите или распакуйте ARM64-пакет **в ту же папку**, сохранив `Data`. Не смешивайте файлы разных архитектур. Файлы ярлыков и настройки JSON не зависят от архитектуры, но абсолютным путям нужна прежняя папка.

Если Yarnelo уже работает из другой папки, закройте его перед запуском новой копии. Установка рядом с переносной версией не переносит её ярлыки автоматически.

## Удаление

Верните нужные перемещённые ярлыки на рабочий стол через меню каждого значка. Для установленной версии используйте **Параметры → Приложения → Установленные приложения → Yarnelo → Удалить**. Удаление убирает только задачу автозапуска этой установки и соответствующую прежнюю запись, а папку `Data` оставляет. Для переносной версии отключите автозапуск в настройках, выйдите из программы и удалите её файлы самостоятельно.

Не удаляйте `Data`, пока не вернули нужные ярлыки. Именно в ней находятся сохранённые копии импортированных `.lnk` и `.url`.

## Сборка для разработчиков

На Windows с .NET Framework 4.8:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\src\Build.ps1 -Architecture x64 -Output .\build\x64
powershell -NoProfile -ExecutionPolicy Bypass -File .\src\Build.ps1 -Architecture x86 -Output .\build\x86
```

Для сборки установщиков дополнительно установите официальный [Inno Setup 6.3 или новее](https://jrsoftware.org/isdl.php):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1 -Architecture x64 -BuildInstaller
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1 -Architecture x86 -BuildInstaller
```

Для нативной ARM64 дополнительно нужен **.NET 8 SDK**. `Build.ps1` использует его компилятор Roslyn с `PlatformTarget=ARM64` и восстанавливает пакет `Microsoft.NETFramework.ReferenceAssemblies.net481` версии **1.0.3** из NuGet. Первая сборка требует доступа к сети. Компилировать можно на Windows x64 или ARM64; запуск результата требует Windows 11 ARM64 с .NET Framework 4.8.1:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\src\Build.ps1 -Architecture arm64 -Output .\build\arm64
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1 -Architecture arm64 -BuildInstaller
```

Результаты появятся в `dist`: ZIP, Setup.exe и SHA-256 для каждого файла. Можно указать `-IsccPath 'C:\путь\ISCC.exe'`, если компилятор расположен нестандартно. Скрипт собирает чистый каталог и отклоняет любые данные профиля, ярлыки и посторонние файлы.
