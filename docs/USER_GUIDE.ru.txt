YARNELO 1.9.2 — панель ярлыков для Windows 10/11 x64,
Windows 10 x86 и Windows 11 ARM64

Архитектура: Параметры → Система → О системе → Тип системы.
x64 — для 64-битных Intel/AMD, ARM64 — для ARM вроде Snapdragon,
x86 — для 32-битной Windows 10. Нативной ARM64 нужны Windows 11
и .NET Framework 4.8.1; Windows 10 ARM64 этим пакетом не поддерживается.

Язык интерфейса: правая кнопка по панели → «Язык / Language» →
«Русский» или «English». Выбор сохраняется и применяется без перезапуска.
При первом запуске русская локаль системы выбирает русский,
остальные локали — английский. Имена ваших ярлыков не меняются.
English guide: Read me.txt / docs/USER_GUIDE.en.txt.

Перетаскивайте ярлыки на панель. Она вмещает до 30 значков. При нехватке
места сначала добавляются ряды или боковые столбцы; значки уменьшаются,
только если ни одна раскладка не помещается на доступном экране.
Настройки → «Количество рядов»: 1, 2, 3 или 4 предпочтительных ряда
(столбца у бокового края). Автоперенос не заменяет сохранённый выбор.
Значки распределяются равномерно; пустые ряды не занимают место.
Один щелчок открывает ярлык. Перетаскивание внутри панели меняет порядок:
значок следует за указателем, соседние значки плавно освобождают место.
Значки можно переносить между рядами, настройка рядов сохраняется.
Esc или отпускание за пределами панели отменяет перенос.
Потяните за ⠿, чтобы свободно переместить панель.
В настройках можно расположить её по центру сверху, снизу, слева
или справа на текущем мониторе. У бокового края панель вертикальная,
значки сохраняют обычную ориентацию.

Кнопка + или правая кнопка на пустом месте открывает меню:
добавление файлов, папок, «Этот компьютер», Корзины и настройки.
Настройки размещены в два столбца без вертикальной прокрутки.
Скругление фона: от 0 (прямые углы) до 100 (капсула).
Также доступны непрозрачность фона, размер, увеличение при
наведении, подписи, режим поверх обычных окон и запуск при входе в Windows.
Настройки → «Подписи под значками» включает компактные однострочные
подписи. Длинные подписи сокращаются по ширине; название также видно
при наведении на значок. Прежний выбор показа подписей сохраняется.
Настройки → «Тема»: Dusk («Сумерки», базовая), Frost («Матовое стекло»),
Graphite («Матовый графит»), Ember («Тёмная бронза»), Aurora («Ночной индиго»).
Панель, меню и настройки следуют выбранной теме; Windows сохраняет
выбор сразу. Цвета, непрозрачность фона и скругление меняются постепенно.
Быстрый новый выбор продолжает переход от текущих цветов к последней
выбранной теме. Значки, размер и положение сохраняются; в покое цвета
не анимируются. При запуске Yarnelo читает настройку системных анимаций
Windows; если они отключены, тема меняется сразу. Во всех пяти темах,
включая Dusk,
используются тонкие акцентные ползунки с круглыми бегунками и скруглённые
галочки. Каждая тема запоминает собственные
непрозрачность и скругление. При первом выборе используются 76% / 22
для Frost, 96% / 12 для Graphite, 85% / 16 для Ember, 88% / 24 для Aurora.
Dusk сохраняет ваш фон после обновления. Возврат к ней или другой
настроенной теме восстанавливает её сохранённый фон. Размер значков,
увеличение, ряды, положение, компактные подписи, автозапуск и автоматическое
добавление ярлыков не сбрасываются. Темы задают характер наведения,
нажатия и перетаскивания; край Aurora подсвечивается при взаимодействии.
В покое панель не переливается. Используются нативные цвета, полупрозрачность и тени.
Значки при изменении непрозрачности фона остаются хорошо видимыми.
Плавное увеличение не перезапускается при каждом движении указателя.
Маленькие старые значки с большими прозрачными полями подгоняются
по видимой области изображения без искажения пропорций.

Автозапуск: Настройки → «Запускать при входе в Windows» создаёт задачу
вашей учётной записи с задержкой входа 10 секунд, точным путём к программе
и её рабочей папкой. Используются обычные права учётной записи;
работа от батареи разрешена, время выполнения не ограничено.
Планировщик заданий → Библиотека планировщика заданий:
Yarnelo.Logon.<SID>. В «Автозагрузке приложений» диспетчера задач
она обычно не показывается; старая строка Polka не отражает её состояние.
Включённая прежняя запись этой установки переносится при первом обычном
запуске после обновления до 1.7.1. Старая запись Run удаляется только после
проверки новой задачи. Отключённый в Windows автозапуск не включается сам;
для явного включения используйте переключатель Yarnelo.
Выключение опции или удаление программы убирает только задачу этой
установки и соответствующую прежнюю запись. При ошибке изменения
переключатель возвращается в прежнее состояние.
Ручной запуск задачи проверяет команду; автоматическое срабатывание
наблюдается при следующем входе в Windows. Принудительный выход из сеанса
или перезагрузка для проверки не нужны.

По умолчанию панель видна, пока другое окно не перекрывает её место.
Лаунчер или другое окно выше панели не скрывает её. После сворачивания,
закрытия или перемещения перекрывающего окна панель возвращается сама,
без щелчка по рабочему столу и без перехвата фокуса. Работа на другом
мониторе не скрывает панель, если её место свободно.
В полноэкранных и безрамочных приложениях на мониторе панели
она скрывается даже при включённом режиме поверх окон. Полноэкранное
приложение на другом мониторе не мешает панели на свободном экране.
При открытии контекстных меню панели и ярлыков панель остаётся видимой.
Запуск панели и её возвращение на рабочий стол не переключают фокус.

Ярлыки .lnk/.url с вашего рабочего стола сохраняются в папке панели,
затем убираются с рабочего стола. Их содержимое и параметры запуска
сохраняются. Обычные файлы и папки добавляются без перемещения.

Настройки → «Автоматически добавлять новые ярлыки с рабочего стола»:
галочка по умолчанию выключена. После включения учитываются новые
.lnk/.url, появившиеся на рабочем столе во время работы Yarnelo.
Включение опции или запуск приложения не импортирует прежние значки.
Обычные файлы и папки игнорируются, дубликаты пропускаются.
Для переноса действует прежняя настройка переноса ярлыков.
При лимите 30 значков оригинал остаётся на рабочем столе без очереди
для последующего импорта. Освободите место и добавьте его через +
или перетаскиванием. Выключение галочки оставляет добавление ручным.

Если личный ярлык ещё заблокирован установщиком, Yarnelo повторит
попытку переноса. Заново созданная установщиком совпадающая копия
переносится снова; изменённая остаётся на рабочем столе с уведомлением.

Общие ярлыки (C:\Users\Public\Desktop) сначала копируются в панель.
При включённом переносе новые общие ярлыки, добавленные автоматически
или вручную, ставятся в очередь запроса на перемещение только этих копий.
Windows может запросить права администратора, когда панель видна,
активен рабочий стол или Yarnelo, вне полноэкранных приложений,
настроек, меню и перетаскивания.
При отмене оригиналы остаются на месте. Отменённый или неудачный запрос
сам не повторяется. Для повтора нажмите + → «Перенести общие ярлыки в панель».
Прежние ожидающие общие ярлыки, найденные при запуске Yarnelo, остаются
для этой отдельной команды меню. В Linux исходные ярлыки по-прежнему
остаются на рабочем столе.

Правая кнопка на значке → «Убрать и вернуть ярлык на рабочий стол»
восстанавливает перемещённый ярлык. Существующие файлы не перезаписываются.
Для возврата общих ярлыков Windows снова запросит права администратора.
Системные значки «Этот компьютер» и «Корзина» добавляются как специальные
ссылки: системные настройки отображения значков на рабочем столе не меняются.

Кнопка приложения есть также в области уведомлений Windows:
показать панель, открыть настройки или выйти. Выход сохраняет содержимое.

Запуск программы: Yarnelo.exe
Профиль обычной установки: %LOCALAPPDATA%\PolkaDock, включая Library.
Профиль переносного ZIP: Data рядом с программой, выбранная portable.mode.
Обновление сохраняет прежний режим хранения, профиль и папку установки.
Сохраняйте portable.mode и Data для существующей переносной установки.
Выберите постоянную папку до добавления ярлыков: пути библиотеки абсолютные.
Главный файл настроек — settings.json, резервная копия — settings.json.bak.

Установленную копию удаляйте через параметры Windows или файл
Uninstall\unins000.exe в папке программы. Перед удалением файлов он
возвращает перемещённые ярлыки на рабочий стол, сохраняет одноимённые
файлы и останавливается при ошибке восстановления. Профиль и библиотека
сохраняются. Перед ручным удалением переносной копии верните ярлыки через
меню значков, отключите автозапуск и выйдите. Сохраняйте Data до возврата.

Приложение работает локально и не отправляет данные в Интернет.
Для x64/x86 нужен .NET Framework 4.8 или 4.8.1,
для Windows 11 ARM64 — .NET Framework 4.8.1.
