YARNELO 1.6.0 — панель ярлыков для Windows 10/11 x64,
Windows 10 x86 и Windows 11 ARM64

Архитектура: Параметры → Система → О системе → Тип системы.
x64 — для 64-битных Intel/AMD, ARM64 — для ARM вроде Snapdragon,
x86 — для 32-битной Windows 10. Нативной ARM64 нужны Windows 11
и .NET Framework 4.8.1; Windows 10 ARM64 этим пакетом не поддерживается.

Язык интерфейса: правая кнопка по панели → «Язык / Language» →
«Русский» или «English». Выбор сохраняется и применяется без перезапуска.
При первом запуске русская локаль системы выбирает русский,
остальные локали — английский. Имена ваших ярлыков не меняются.
English guide: Read me.txt / docs/USER_GUIDE.en.txt.

Перетаскивайте ярлыки на панель. Она вмещает до 30 значков и сама
уменьшает их размер, если иначе они не помещаются на экране.
Настройки → «Количество рядов»: 1, 2, 3 или 4. Значки равномерно
распределяются по рядам, а порядок читается слева направо, сверху вниз.
При небольшом числе значков лишние ряды не занимают место.
Один щелчок открывает ярлык. Перетаскивание внутри панели меняет порядок:
значок следует за указателем, соседние значки плавно освобождают место.
Значки можно переносить между рядами, настройка рядов сохраняется.
Esc или отпускание за пределами панели отменяет перенос.
Потяните за ⠿ слева, чтобы переместить панель.

Кнопка + или правая кнопка на пустом месте открывает меню:
добавление файлов, папок, «Этот компьютер», Корзины и настройки.
В настройках доступны непрозрачность фона, размер, увеличение при
наведении, подписи, режим поверх обычных окон и запуск при входе в Windows.
Значки при изменении непрозрачности фона остаются хорошо видимыми.
Плавное увеличение не перезапускается при каждом движении указателя.
Маленькие старые значки с большими прозрачными полями подгоняются
по видимой области изображения без искажения пропорций.

По умолчанию панель видна, пока другое окно не перекрывает её место.
Лаунчер или другое окно выше панели не скрывает её. После сворачивания,
закрытия или перемещения перекрывающего окна панель возвращается сама,
без щелчка по рабочему столу и без перехвата фокуса. Работа на другом
мониторе не скрывает панель, если её место свободно.
В полноэкранных и безрамочных приложениях на мониторе панели
она скрывается даже при включённом режиме поверх окон. Полноэкранное
приложение на другом мониторе не мешает панели на свободном экране.
При открытии контекстных меню панели и ярлыков панель остаётся видимой.
Запуск панели и её возвращение на рабочий стол не переключают фокус.

Ярлыки .lnk/.url с вашего рабочего стола сохраняются в папке панели,
затем убираются с рабочего стола. Их содержимое и параметры запуска
сохраняются. Обычные файлы и папки добавляются без перемещения.

Общие ярлыки (C:\Users\Public\Desktop) сначала копируются в панель.
Windows запросит права администратора для изменения общего рабочего
стола. При отмене запроса оригиналы остаются на месте. Чтобы повторить
перенос, нажмите + → «Перенести общие ярлыки в панель».

Правая кнопка на значке → «Убрать и вернуть ярлык на рабочий стол»
восстанавливает перемещённый ярлык. Существующие файлы не перезаписываются.
Для возврата общих ярлыков Windows снова запросит права администратора.
Системные значки «Этот компьютер» и «Корзина» добавляются как специальные
ссылки: системные настройки отображения значков на рабочем столе не меняются.

Кнопка приложения есть также в области уведомлений Windows:
показать панель, открыть настройки или выйти. Выход сохраняет содержимое.

Запуск программы: Yarnelo.exe
Настройки и сохранённые ярлыки: папка Data рядом с программой.
В архивной версии маркер portable.mode включает хранение данных рядом
с программой. Выберите постоянную папку до добавления ярлыков:
в заполненном профиле сохраняются абсолютные пути. Для обновления
заменяйте файлы программы в той же папке, сохраняя Data.
Главный файл настроек — settings.json, резервная копия — settings.json.bak.

Перед удалением программы верните нужные ярлыки на рабочий стол через
меню значков. Отключите автозапуск в настройках и закройте Yarnelo через
меню. Папку Data можно сохранить как резервную копию.

Приложение работает локально и не отправляет данные в Интернет.
Для x64/x86 нужен .NET Framework 4.8 или 4.8.1,
для Windows 11 ARM64 — .NET Framework 4.8.1.
