YARNELO 1.7.3 — shortcut dock for Windows 10/11 x64,
Windows 10 x86 and Windows 11 ARM64

Choose the package matching Settings → System → About → System type:
x64 for Intel/AMD x64, ARM64 for ARM processors such as Snapdragon,
x86 for 32-bit Windows 10. Native ARM64 needs Windows 11 and
.NET Framework 4.8.1; Windows 10 ARM64 is not supported by that package.

Language: right-click the dock → Language / Язык → English or Русский.
The choice is saved and applied without restarting. On first launch,
a Russian system locale selects Russian; other locales select English.
Your own shortcut names are not changed.
Русское руководство: Прочитай меня.txt / docs/USER_GUIDE.ru.txt.

Drop shortcuts on the dock. It holds up to 30 icons. If space runs out,
it first adds rows or side columns to keep the requested icon size;
icons are reduced only if no layout fits the available screen.
Settings → Rows: 1, 2, 3 or 4 preferred rows (columns at the side).
Automatic wrapping does not replace your saved preference.
Icons are balanced across rows; empty rows take no space.
Click once to launch. Drag within the dock to rearrange shortcuts:
the icon follows the pointer while neighbors smoothly move aside.
You can move icons between rows; the row setting is saved.
Esc or releasing outside the dock cancels the move.
Drag the handle to move the entire dock freely.
Settings → Position centers it at the top, bottom, left or right edge
of its current monitor. Side docks are vertical; icons remain upright.

The + button or right-clicking empty space opens the menu for adding
files, folders, This PC, Recycle Bin, choosing a language and settings.
Settings use two columns without vertical scrolling and fit the screen.
Corner rounding runs from 0 (square corners) to 100 (capsule).
Settings also control background opacity, icon size, hover magnification,
labels, showing above ordinary windows, and startup at sign-in.
Settings → Show icon labels enables compact one-line captions.
Long captions are shortened to fit; hovering an icon shows its name.
Your previous choice of showing labels is retained.
Changing background opacity keeps icons readable.
Hover animations do not restart with every pointer movement.
Older icons with large transparent margins are fitted to their visible
image area while retaining their proportions.

Startup: Settings → Start when signing in to Windows creates a task
for your account with a 10-second logon delay, the exact program path
and its working directory. It uses ordinary account permissions,
runs on battery power and has no execution time limit.
Task Scheduler → Task Scheduler Library lists it as Yarnelo.Logon.<SID>.
It does not normally appear under Task Manager → Startup apps;
an old Polka row there is not the new task's status.
An enabled legacy entry for this installation migrates on the first
normal launch after updating to 1.7.1. The old Run entry is removed
only after the new task has been verified. Windows-disabled startup
is not enabled automatically; use the switch to enable it explicitly.
Turning the switch off, or uninstalling, removes only this installation's
task and matching legacy entry. A failed change restores the switch.
A manual task launch checks the command; automatic triggering is observed
at the next Windows sign-in. No forced sign-out or restart is needed.

By default the dock is visible while no other window covers its space.
A launcher or window above its space does not hide it. After a covering
window is minimized, closed or moved, the dock returns automatically,
without a desktop click or taking focus. Activity on another monitor
does not hide the dock when its own space is free.
Fullscreen and borderless apps on the dock's monitor hide it even with
the option to show above ordinary windows enabled. Fullscreen apps on
another monitor leave the dock available on an unobstructed display.
The dock stays visible while its own context menus are open.
Launching or restoring the dock does not take focus.

With desktop shortcut transfer enabled, desktop .lnk/.url files are
stored in the dock's folder and removed from the desktop. Their contents
and launch arguments are preserved. Ordinary files and folders are
added without moving them.

Settings → Automatically add new desktop shortcuts is off by default.
Enable it to add new .lnk/.url appearing on the desktop while Yarnelo
is running. Enabling the option or starting the app does not import
existing icons. Ordinary files and folders are ignored, and duplicates
are skipped. Desktop shortcut transfer follows its existing setting.
At the 30-icon limit the original stays on the desktop; it is not queued
for later. Make room and add it manually with + or drag-and-drop.
Turning the option off keeps all adding manual.

Shared desktop shortcuts (C:\Users\Public\Desktop) are copied first.
Windows asks for administrator rights to change the shared desktop.
Canceling leaves the originals in place. To retry, choose
+ → Move shared shortcuts into the dock.
Automatic addition copies shared shortcuts without opening an
administrator prompt. Use that explicit menu action to move them.

Right-click an icon → Remove and restore shortcut to desktop restores
a moved shortcut. Existing files are never overwritten.
Restoring shared desktop shortcuts may require administrator rights.
This PC and Recycle Bin are added as special links; Windows desktop-icon
settings are not changed.

The Windows notification-area icon also provides Show dock, Settings
and Exit. Exiting saves the dock's contents.

Program: Yarnelo.exe
Settings and imported shortcuts: Data beside the program.
The portable.mode marker keeps data beside the executable. Pick a
permanent location before adding shortcuts: profiles use absolute paths.
To update, replace program files in the same folder and retain Data.
Settings: settings.json; backup: settings.json.bak.
A new installer does not automatically import a separate portable copy.

Before removing Yarnelo, restore required shortcuts through icon menus,
disable startup at sign-in and exit the app. Keep Data as a backup.
The installer also preserves Data during update and removal.

Yarnelo works locally and does not send your data to a server.
Requires .NET Framework 4.8 or 4.8.1 on x64/x86,
or .NET Framework 4.8.1 on Windows 11 ARM64.
