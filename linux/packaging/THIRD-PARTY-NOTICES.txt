This executable contains Python, PySide6, Shiboken6, Qt, bzip2 and their dependencies.
Their available license notices are copied into this distribution's licenses/
directory from the build environment. Python's installed LICENSE is included
when available. The PyInstaller bootloader exception allows bundling applications

bzip2: https://sourceware.org/bzip2/
PyInstaller: https://pyinstaller.org/en/stable/license.html

The application is a one-directory bundle. Qt shared libraries live in
_internal/PySide6/Qt/lib/ and are dynamically loaded. They are not statically
linked into Yarnelo. You may replace those LGPL components with compatible
modified versions in your own copy, subject to their respective licenses.
Repacking an AppImage is unnecessary for this: use --appimage-extract and run
the resulting squashfs-root/AppRun after replacing compatible libraries.

The exact bundled versions are recorded in build-versions.txt. References above
identify upstream source repositories; corresponding release tags follow those
recorded versions. This notice does not grant a license to Yarnelo itself.

AppImage runtime
----------------
The AppImage format embeds the official AppImage/type2-runtime executable,
without Yarnelo changes to its source. Its MIT license and third-party notices
are included in licenses/AppImage-runtime/LICENSE, including references to the
statically linked musl, libfuse (LGPL 2), squashfuse, zstd and zlib components.

Original source: https://github.com/AppImage/type2-runtime
Build instructions: https://github.com/AppImage/type2-runtime/blob/main/BUILD.md
When built by the project CI, build-tools/*.source.json records the exact
downloaded tool/runtime asset, verified SHA-256, source commit and source archive
URL. See also corresponding-sources.txt. AppImage tooling licenses do not change
the license of Yarnelo's original code or artwork.
