<h1 align="center">Yarnelo</h1>

<p align="center">Ваши ярлыки. В одном месте.</p>

Yarnelo — полупрозрачная панель ярлыков для **Windows 11 x64**, вдохновлённая формой macOS Dock. Соберите нужные приложения, папки и файлы в одном месте, настройте внешний вид и освободите рабочий стол.

**[Скачать последнюю версию](https://github.com/feogrim-cloud/Yarnelo/releases/latest)** · [Инструкция](docs/USER_GUIDE.ru.txt) · [Сообщить о проблеме](https://github.com/feogrim-cloud/Yarnelo/issues)

## Возможности

- До **30 ярлыков** в **1, 2, 3 или 4 рядах**, включая «Этот компьютер» и Корзину.
- Настраиваемые непрозрачность фона, размер значков, увеличение при наведении и подписи.
- Плавные анимации наведения, нажатия и перестановки: значок следует за мышью, соседние освобождают место.
- Перетаскивание ярлыков с рабочего стола и восстановление через меню значка.
- Перемещение самой панели, меню в области уведомлений и автозапуск по желанию.
- Подгонка значков с большими прозрачными полями по видимой области изображения.

По умолчанию панель скрывается, когда другое окно перекрывает её место, и возвращается сама, когда оно освобождается. Окно выше панели или работа на другом мониторе её не скрывают. В настройках можно включить показ поверх обычных окон.

Полноэкранные и безрамочные приложения на мониторе панели скрывают её даже в режиме поверх окон. Возвращение панели не переключает фокус. Приложение работает локально, без отправки данных в Интернет.

## Установка и первый запуск

1. Скачайте архив для Windows x64 со страницы [Releases](https://github.com/feogrim-cloud/Yarnelo/releases/latest).
2. Полностью распакуйте его в отдельную папку, доступную для записи. Это портативная версия без установщика.
3. Запустите `Yarnelo.exe`. Папка `Data` появится рядом с программой.
4. Перетащите ярлыки на панель или нажмите **+**. Правой кнопкой открывается контекстное меню, за ручку слева можно переместить панель.

Требуются **Windows 11 x64** и **.NET Framework 4.8**. Текущая сборка не подписана цифровым сертификатом; Windows может показать уведомление о неизвестном издателе.

### Что происходит с ярлыками

При включённом переносе ярлыки `.lnk` и `.url` с вашего рабочего стола сохраняются в `Data/Library`, затем убираются с рабочего стола. Их содержимое и параметры запуска сохраняются. Обычные файлы и папки добавляются без перемещения.

Чтобы вернуть перемещённый ярлык, нажмите на него правой кнопкой → **«Убрать и вернуть ярлык на рабочий стол»**. Существующие файлы не перезаписываются. Для переноса и возврата общих ярлыков Windows запрашивает права администратора; при отмене исходные ярлыки остаются на месте.

Добавление «Этот компьютер» и Корзины не меняет системные настройки значков рабочего стола.

### Данные, обновление и удаление

Настройки находятся в `Data/settings.json`, их резервная копия — в `Data/settings.json.bak`. Ярлыки хранятся в `Data/Library`. Маркер `portable.mode` включает хранение данных рядом с программой; сохраняйте его вместе с приложением.

Для обновления закройте Yarnelo через меню, сохраните резервную копию `Data` и замените файлы программы из нового архива в той же папке. Перед удалением верните нужные ярлыки на рабочий стол и отключите автозапуск в настройках.

## Сборка из исходников

Приложение написано на **C# / WPF** для **.NET Framework 4.8**. Сборка использует системный компилятор Framework; отдельный .NET SDK, NuGet и Visual Studio не нужны.

Из корня репозитория в Windows PowerShell:

```powershell
.\src\Build.ps1 -Output .\build
.\build\Yarnelo.exe
```

Генератор иконки создаёт PNG, SVG и ICO с несколькими размерами. Собранное приложение и необходимые файлы появятся в `build`.

Проверки:

```powershell
.\scripts\Test.ps1
```
